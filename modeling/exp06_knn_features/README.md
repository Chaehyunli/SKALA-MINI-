# 6차 실험: 이웃 라벨 특성 (kNN label features)

## 목적
4차 최고점(스태킹 33개 + 임계값, CV F1 0.8282)을 넘는다. 예측 데이터는 학습 데이터와 구조가 비슷한 화합물이 많다(유사도 0.8 이상 53%). 그래서 가장 비슷한 학습 화합물들의 라벨을 직접 특성으로 주는 방법을 시험했다.

## 설정
| 항목 | 내용 |
|---|---|
| 특성 | ECFP·FCFP 각각: 최대 유사도, 상위 5개 평균 유사도, 유사도 가중 라벨 평균(k = 1, 3, 5, 10), 유사도 0.7 이상 이웃의 라벨 평균·개수 → 16개 |
| 누수 방지 | 이웃은 그 모델의 학습 데이터 안에서만 찾는다. 학습 행은 자기 자신을 뺀 이웃(leave-one-out), 검증·테스트·예측 행은 학습 데이터 전체 (`knnfeat.KnnAugmented`) |
| 모델 | ① 3차 튜닝 모델 3개(+MACCS) + 이웃 특성 16개 ② 이웃 특성 16개 + 연속형 15개만 쓰는 작은 모델 2개(LightGBM, 로지스틱 회귀) |
| 비교 | 같은 10 fold, 짝지은 보정 t-검정 |

## 결과
| 모델 | 3차 F1 | +이웃 특성 F1 | 차이 | p값 | 10 fold 중 개선 |
|---|---|---|---|---|---|
| LightGBM | 0.8215 | 0.8091 | −0.0124 | 0.002 | 0 |
| XGBoost | 0.8218 | 0.8105 | −0.0113 | 0.003 | 0 |
| RandomForest | 0.8212 | 0.7991 | −0.0221 | <0.001 | 0 |

| 앙상블 (fold 안 임계값) | F1 | 4차 최종 대비 | p값 |
|---|---|---|---|
| 4차 최종: 스태킹 33개 | 0.8282 | — | — |
| 33개 + 6차 작은 모델 2개 (6차 최고) | 0.8267 | −0.0015 | 0.52 |
| 33개 + 6차 5개 | 0.8257 | −0.0025 | 0.24 |
| 3차 튜닝 3개 + 6차 5개 | 0.8241 | −0.0041 | 0.19 |

이웃 특성 + 연속형만 쓰는 작은 모델은 F1 0.794~0.796으로, 1차 KNN(0.765)보다는 높지만 트리 모델보다 낮다.

## 판단
1. 이웃 라벨 특성은 단독으로도, 앙상블에서도 해롭다. 세 모델 모두 10 fold 전부에서 떨어졌다.
2. 원인: 구조가 거의 같은 화합물끼리도 라벨 일치율이 0.81이라 이웃 라벨에 노이즈가 많다. 트리는 이 강력해 보이는 특성에 먼저 분할을 걸어, 원래 특성(clogp·TPSA·Fingerprint)을 덜 쓰게 된다.
3. 이웃 라벨 정보는 이미 Fingerprint를 통해 트리 모델이 간접적으로 쓰고 있었다. 다시 명시적으로 주는 것은 추가 정보가 아니었다.
4. 4차 최종을 그대로 최고로 유지한다.
