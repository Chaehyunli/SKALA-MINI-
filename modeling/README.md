# Day2 모델링 실험 요약 (1~9차)

## 공통 설정
- 데이터: train.csv 8,349행 → 정제(라벨 충돌 parent 제외, parent당 1행) → 8,000행
- 분할(`common/splits.csv`, 고정): parent 그룹 기준. 테스트 20%(1,600행), 개발 80%(6,400행)를 5-fold × 2회 = 10 fold로 검증
- 평가: F1 (1 = 독성 없음이 Positive). 비교는 fold별 짝지은 보정 t-검정. 테스트 세트는 차수별 최고 방법 확인에만 사용
- 제출 형식: 교수님 예시와 같은 `SMILES, output` 927행 (`common/submission.py`가 행 수·순서·값을 검사)
- 실행 순서: 1 → 2 → 3 → 4 → 6 → 7 → 8 → 9 → 5차 (5차 그래프 신경망은 보류 후 마지막 실행)

## 최종 결론: 8차 스태킹(임계값 0.5)
- 검증 CV F1 0.8309로 검증한 방법 중 최고이고, 실제 채점에서도 0.845로 최고 점수다. 제출 파일은 `exp08_pseudo_label/predict_output_임채현_8차_thr0.5.csv`.
- 여러 관점의 모델(튜닝 트리 + 입력이 다른 모델 + 준지도 모델)을 스태킹한 효과가 검증(3차 0.8218 → 8차 0.8309)과 실제 채점(0.84 → 0.845) 모두에서 같은 방향으로 나타났다.
- 임계값을 낮춘 버전(4차, 0.43)은 실제 채점에서 손해였다(0.8378). 최종은 임계값 0.5를 유지했다.
- 5차 그래프 신경망은 교차검증을 끝내지 못해 성능이 확인되지 않았으므로 최종 결론에서 제외하고 후속 과제로 둔다.

4. 각 폴더의 `predict_submission.ipynb`로 그 차수 제출 파일 생성 (6차 이후는 `common/build_predict_generic.py`로 생성)
