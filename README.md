# 신약 후보물질 독성 여부 이진분류 (Mini Project, 2조)

SMILES와 fingerprint·descriptor로 화합물의 독성 여부를 예측한다. 평가지표는 **F1**이고, 라벨 1 = 독성 없음(Positive), 0 = 독성 있음이다.

## Day1: 데이터와 EDA 핵심
- 정제: parent(염 제거·입체 제거 SMILES) 기준 중복 312행, 라벨 충돌 37그룹(81행)을 정리해 **8,000행**(label 1 = 54.2%). 전부 1로 예측해도 F1 0.703이다.
- 행이 MolWt 오름차순 블록 2개로 정렬돼 있어 CV는 반드시 shuffle한다.
- clogp가 가장 강한 신호(높을수록 독성), TPSA·HBD·산소 수는 높을수록 비독성. MolWt 단독은 신호가 없다.
- 구조가 비슷해도(유사도 0.8 초과) 라벨이 다른 activity cliff 쌍이 514개 있어 성능 상한이 낮다.
- 최종 컬럼 1,042개 = ECFP 644 + FCFP 383 + descriptor 3 + RDKit 파생 12. 같은 분자가 학습·검증에 걸치지 않도록 parent 그룹 CV, scaffold CV로 재검증했다.

## 공통 실험 설정 (Day2)
- 분할(`modeling/common/splits.csv`, 고정): parent 그룹 기준. 테스트 20%(1,600행), 개발 80%(6,400행)를 5-fold × 2회 = 10 fold로 검증한다.
- 비교는 fold별 짝지은 보정 t-검정(Nadeau & Bengio). 테스트 세트는 차수별 최고 모델 확인에만 쓴다.
- 제출 형식은 `SMILES, output` 927행. `common/submission.py`가 행 수·순서·값을 검사한다.

## 차수별 정리

### 1차: 모델 계열 비교
- 입력 1,042컬럼을 고정하고 9개 모델을 같은 조건에서 비교했다.
- RandomForest 0.8177, LightGBM 0.8150, XGBoost 0.8131이 상위이며 서로 통계적으로 구분되지 않는다(p = 0.44, 0.41). 트리 계열이 1~5위, KNN(0.7652)이 최하위다.
- 연속형 특성(clogp, TPSA 등)의 기여가 컬럼당 10~45배로 컸고, 처음 보는 구조에서는 정답률이 0.74로 떨어졌다. 이것이 2차 가설의 근거가 됐다.
- 상세: [exp01 README](modeling/exp01_model_comparison/README.md)

### 2차: 입력 표현 변경
- RDKit 217, Mordred, PTFP, MACCS, AP/TT, 입체 count FP, SVD 차원 축소를 상위 트리 3개로 비교했다.
- 통계적으로 의미 있게 오른 변형은 없었다(차이 −0.007 ~ +0.004, p ≥ 0.19). descriptor를 늘리면 오히려 평균 0.0024 낮아졌고, SVD는 트리에 해로웠다(LightGBM −0.015).
- 대신 입력이 다른 모델은 서로 예측이 달라(순위 상관 0.91~0.94) 앙상블 재료로 가치가 있었다.
- 상세: [exp02 README](modeling/exp02_feature_variants/README.md)

### 3차: 하이퍼파라미터 튜닝
- +MACCS 입력으로 LightGBM·XGBoost·RandomForest를 Optuna로 튜닝했다.
- 세 모델 모두 0.821~0.822로 올랐고, 유의한 개선은 XGBoost뿐이다(+0.0076, p = 0.005, 10 fold 모두 개선). 학습률을 낮추고 트리 수를 늘리는 방향이 공통이었다.
- 테스트 F1은 0.809로 CV보다 낮아 단일 모델의 불안정성이 드러났다. 4차에서 앙상블로 보완하기로 했다.
- 상세: [exp03 README](modeling/exp03_tuning/README.md)

### 4차: 임계값 조정과 앙상블
- 1~3차 33개 모델의 OOF 예측을 재료로 평균·스태킹·탐욕적 선택을 비교했다. 임계값과 가중치는 모두 fold 안에서 골랐다.
- 스태킹 33개 + 임계값 0.43이 CV F1 0.8282로 최고다(기준 대비 +0.006, p = 0.08). 임계값은 단일 모델에는 효과가 없었고 앙상블에서만 +0.002~0.005 효과가 있었다.
- 1차 0.8177에서 시작해 2차 +0.001, 3차 +0.004, 4차 +0.006으로 총 +0.011 올랐다. 현재 특성의 상한은 0.83 근처로 보고, 구조를 직접 학습하는 GNN 등을 다음 후보로 정했다.
- 상세: [exp04 README](modeling/exp04_threshold_ensemble/README.md)

### 5차: 그래프 신경망 (Chemprop D-MPNN)
- 목적: 1~4차는 모두 Fingerprint·descriptor 기반이라 비슷하게 틀린다. 분자 그래프를 직접 학습하는 모델로 앙상블 다양성을 높이려 했다. Chemprop 2 D-MPNN(메시지 전달 3단계, 은닉 300) + 분자 단위 특성 15개.
- 6~9차를 먼저 진행해 마지막에 실행했고, 교차검증을 끝내지 못했다. fold 0에서 5 epoch만으로 F1 0.781, AUC 0.823을 확인한 것이 전부다.
- 마감 대응 예비안으로 8차 확률과 GNN 확률을 logit 0.8 : 0.2로 결합하고 임계값 0.5로 제출 파일(`predict_output_임채현_5차_thr0.5.csv`)을 만들었다. 검증은 하지 않았으므로 최종 결론에서 제외하고 후속 과제로 둔다.
- 상세: [exp05 README](modeling/exp05_gnn/README.md)

### 6차: 이웃 라벨 특성 (kNN label features)
- 가장 비슷한 학습 화합물의 최대 유사도, 이웃 라벨 평균 등 16개를 특성으로 추가했다. 누수를 막기 위해 학습 행은 자기 자신을 뺀 이웃만 사용했다.
- **효과 없음, 오히려 해로움.** 3차 튜닝 3개 모델 모두 10 fold 전부에서 떨어졌다(LightGBM 0.8215 → 0.8091, XGBoost 0.8218 → 0.8105, RandomForest 0.8212 → 0.7991). 앙상블에 넣어도 6차 최고는 0.8267로 4차(0.8282)보다 낮다.
- 원인: 유사도가 높아도 라벨 일치율이 0.81이라 이웃 라벨에 노이즈가 많고, 트리가 이 특성에 먼저 분할을 걸어 clogp·TPSA 등을 덜 쓰게 된다. 이웃 정보는 Fingerprint를 통해 이미 간접적으로 쓰이고 있었다.
- 상세: [exp06 README](modeling/exp06_knn_features/README.md)

### 7차: 시드 평균과 튜닝 설정 옮기기
- ① 3차 튜닝 XGBoost·LightGBM을 시드 5개로 평균, ② 2차에서 앙상블 기여가 컸던 입력(+AP/TT, +PTFP, +Mordred, 입체 count FP)에 3차 튜닝 설정을 그대로 적용했다.
- 시드 평균은 효과가 없었다(XGBoost −0.0003, LightGBM −0.0015). 튜닝 설정을 옮긴 입체 count FP × RandomForest는 F1 0.8229로 단일 모델 중 최고다(2차 같은 입력 대비 +0.0038, p = 0.17).
- 4차 33개 + 7차 6개 = 스태킹 39개 + 임계값 0.42가 CV F1 0.8299(4차 대비 +0.0018, p = 0.49), 테스트 F1 0.826이다. 개선 폭이 0.002 이하로 작아져 현재 특성으로는 상한(약 0.83)에 가까워졌다.
- 상세: [exp07 README](modeling/exp07_seed_avg/README.md)

### 8차: 준지도 학습 (pseudo-labeling) — 최종 채택
- 라벨 없는 predict_input 927행 중 비독성 확률 ≥ 0.85 또는 ≤ 0.15인 행(fold당 약 530~570행)에 예측 라벨을 붙여 3차 튜닝 LightGBM·XGBoost를 다시 학습했다. 실제 라벨은 쓰지 않았고, CV에서는 각 fold의 학습 부분만으로 의사 라벨을 만들었다.
- 단독 효과는 거의 없었다(XGBoost +0.0008, LightGBM −0.0023). 확신이 높은 행은 모델이 이미 잘 맞히는 쉬운 행이기 때문이다.
- 그래도 7차 39개에 두 모델을 더한 스태킹 41개 + 임계값 0.42가 CV F1 0.8309로 최고다(4차 대비 +0.0028, p = 0.19). 테스트 F1은 0.825(임계값 0.5에서 0.821), AUC 0.879다. 임계값 0.5 버전의 실제 채점 F1은 **0.845**로 가장 높다.
- 상세: [exp08 README](modeling/exp08_pseudo_label/README.md)

### 9차: Mordred 재도전
- ① descriptor만 쓰는 모델(Descriptor + RDKit 217 + Mordred 700 = 883개), ② base + Mordred에 3차 튜닝 LightGBM 설정을 적용했다.
- descriptor만으로도 F1 0.812~0.813이 나왔지만 Fingerprint를 쓴 모델보다 낮다. Mordred + 튜닝 LightGBM은 0.8114 → 0.8154로 올랐으나(p = 0.17) 3차 튜닝 모델에는 못 미친다.
- 8차 41개에 9차 3개를 더한 스태킹 44개 + 임계값 0.38은 CV F1 0.8295로 8차보다 0.0014 낮다(p = 0.44). 8차 최종을 그대로 유지한다.
- 상세: [exp09 README](modeling/exp09_mordred_retry/README.md)

## 핵심 정리
- 최종 채택: **8차 스태킹 41개(임계값 0.5)**. 검증 CV F1 0.8309로 가장 높고 실제 채점 F1도 0.845로 가장 높다. 1차 단일 모델(CV 0.8177)에서 +0.013 올랐다.
- 단일 모델·입력 표현·튜닝은 F1 0.82 안팎에서 포화됐다. 올라간 것은 서로 다른 입력·모델을 스태킹한 경우뿐이다.
- 6차(이웃 라벨)와 9차(Mordred 재도전)처럼 새 특성을 더한 시도는 오히려 낮아졌다. 7차 이후 개선 폭은 0.002 이하이고 p 0.19~0.49로 통계적으로 확정되지는 않는다.
- 임계값을 낮추면 CV에서는 이득이었지만 실제 채점에서는 손해(4차 0.8378)여서 최종은 0.5를 유지했다.
- 한계: 구조가 거의 같은 화합물끼리도 라벨 일치율이 0.81이라 현재 특성으로는 F1 0.83 근처가 상한에 가깝다. 구조를 직접 학습하는 GNN(5차)은 교차검증을 끝내지 못해 후속 과제로 남았다.

1. `pip install -r requirements.txt` (mordredcommunity, optuna, pyarrow 포함)
2. `modeling/common/make_splits.py` (`splits.csv`가 이미 있으면 생략)
3. 1차 → 2차(`build_features.py`로 cache 생성 후 노트북) → 3차 → 4차 → 6차 → 7차 → 8차 → 9차 순서로(5차는 `pip install chemprop` 후 마지막에) 각 폴더의 노트북 실행. 노트북의 `RUN_CV`·`RUN_TUNE`을 `False`로 두면 저장된 `results/`만 불러온다.
4. 각 폴더의 `predict_submission.ipynb`로 그 차수의 `predict_output_임채현_N차.csv`를 만든다.
